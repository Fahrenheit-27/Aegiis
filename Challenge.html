SQL Injection Prevention

Medium
Description
Hints
Submissions

In this challenge, you need to identify and fix an SQL injection vulnerability in a user authentication system.

Background

Your company's web application has a login system that queries a database to verify user credentials. Security audit has revealed that the current implementation is vulnerable to SQL injection attacks.

Objective

Refactor the provided code to prevent SQL injection attacks while maintaining the functionality. Your solution should:

  • Prevent SQL injection attacks
  • Maintain the existing functionality
  • Follow security best practices
  • Be efficient and readable

Vulnerable Code

function authenticateUser(username, password) {
  const query = `SELECT * FROM users 
                WHERE username = '${username}' 
                AND password = '${password}'`;
  
  const user = database.execute(query);
  
  if (user.length > 0) {
    return { success: true, user: user[0] };
  } else {
    return { success: false, message: 'Invalid credentials' };
  }
}

Examples

Exploit example:

Username: admin' --

Password: anything

Resulting query:

SELECT * FROM users 
WHERE username = 'admin' --' AND password = 'anything'

This would comment out the password check, allowing unauthorized access.

Test Cases

Your solution will be tested against the following:

  • Legitimate login attempts with correct credentials
  • Legitimate login attempts with incorrect credentials
  • Multiple SQL injection attack patterns
